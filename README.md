# Multithreaded Hotel API (Java)

A containerized back-end web application built with Java and Spring Boot that manages hotel room reservations. This project was developed to demonstrate advanced asynchronous programming, dynamic localization, and seamless cloud deployment preparation using Docker.

🚀 Key Features

* Multithreaded Processing: Utilizes Java's multithreading capabilities to concurrently load and display welcome messages in multiple languages without blocking the main execution thread.
* Localization (i18n): Dynamically formats currency (CAD, EUR, USD) and localized text based on resource bundles for international users.
* Time Zone Conversion: Calculates and displays real-time live presentation schedules simultaneously across multiple global time zones (ET, MT, UTC).
* Containerization: Fully containerized using a custom Dockerfile, ensuring a consistent and isolated deployment environment.

💻 Technology Stack

* Language: Java 17
* Framework: Spring Boot, Spring Data JPA
* Concepts: Multithreading, Asynchronous Programming, Localization (i18n), Containerization
* Tools: Docker, Maven, Git
